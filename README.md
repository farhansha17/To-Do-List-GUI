# To-Do List App

A simple **To-Do List App** built with **Python** and **Tkinter** to manage daily tasks efficiently.

## Features
✅ Add tasks to the list
✅ Mark tasks as completed
✅ Delete tasks from the list
✅ Simple and user-friendly interface

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/farhansha17/todo-list-app.git
   cd todo-list-app
   ```
2. Run the application:
   ```sh
   python todo_list_app.py
   ```

## How to Use
1. **Enter a task** in the input field and click **Add Task**.
2. **Select a task** and click **Mark as Done** to mark it as completed.
3. **Select a task** and click **Delete Task** to remove it from the list.
